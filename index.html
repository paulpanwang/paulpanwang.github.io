Hi! I'm Panwang Pan, a senior researcher at ByteDance Seed. I work on multimodal agents for real-time perception, interaction, tool use, and feedback-driven improvement.

My through-line is RSI for real-world agents: perceive continuously, interact with people and tools, observe outcomes, and use feedback to refine behavior. I am especially interested in:

  • (i) Interactive multimodal agents: real-time audio-visual assistants (SeedRealtime), interactive and proactive MLLM evaluation (Interactive & Proactive Agent), human-like SAM agents for reasoning segmentation (SAM-Veteran), and intelligent photo-retouching tool use (JarvisArt).
  • (ii) Agent environments and generation: dynamic scene worlds, long-horizon visual memory and controllable video generation, including DynamicVerse, Ring Forcing, Diff4Splat, MoVieS, and ID-Crafter.

🛠 Open RSI Lab [Home]

I build RSI systems where agents perceive continuously, interact with people, software, and devices, observe outcomes, and use feedback to improve future behavior.

Digital-World RSI Agents use search, query, browser, computer-use, phone, CLI, and visual understanding tools, then convert digital outcomes into reusable feedback. Real-World RSI Agents connect smart glasses, vehicles, robots, sensors, phones, and computers, then learn from feedback across open-world environments.
